🌿 Living Environmental Ambience

  • ✨ Procedural Hills: Rolling perimeter terrain modeling real East Texas pineywoods topography.
  • ☁️ Atmospheric Cloud Field: 50+ procedural puff meshes drifting on prevailing breeze vectors.
  • 🦅 Kinematic Bird Flocks: Natural flocking paths with continuous wing-flapping sinusoidal animation.
  • 🦋 Butterfly Garden Swarm: Erratic, fluttering flight paths pollinating native Texas flora.
  • ⛲ Fountain Particle Jet: Central multi-tier fountain with pulsing upward spray plumes.

⚡ 3D Engine Performance Suite

  • 🚀 Static Shadow Caching: Rendered static geometry shadows once (autoUpdate=false), saving 12–15ms per frame.
  • 📱 DPR Scaling: Detects low-spec hardware / mobile to cap DPR at 1.0 (desktop 1.35), reducing fill-rate by 54%.
  • 💾 VRAM Optimization: Shadow map halved to 2048 with normalBias: 0.04, cutting VRAM by 75–93%.
  • 🗑️ Zero GC Jitter: Hoisted projection vectors in pin updates, stopping 60 allocations/sec.
  • 💤 Tab Sleep Hook: Render loop halts when tab is backgrounded (0% GPU/CPU consumption).
